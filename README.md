# Archaeological Expedition — QA Testing

## О проекте

Проект посвящён ручному тестированию веб-формы регистрации участников археологической экспедиции.

Основная цель — проверить соответствие функциональности и пользовательского интерфейса требованиям технического задания, выявить дефекты и оценить качество тестируемого продукта.

## Цели тестирования

- Проверка соответствия формы требованиям технического задания.
- Проверка корректности валидации пользовательских данных.
- Проверка работы интерактивных элементов.
- Проверка отправки и очистки формы.
- Выявление, документирование и приоритизация дефектов.
- Оценка результатов тестирования с использованием метрик.

## Область тестирования

В рамках проекта проверялись:

- Текстовые поля: имя и фамилия, email, контактный номер.
- Поле даты рождения и проверка возрастных ограничений.
- Выпадающий список опыта в археологии.
- Чекбоксы и радиокнопки.
- Ползунок желаемой заработной платы.
- Загрузка файлов.
- Поле дополнительного комментария.
- Согласие с условиями использования.
- Отправка и очистка формы.

## Инструменты

| Инструмент | Назначение |
|---|---|
| Excel | Разработка чек-листов и тест-кейсов, фиксация результатов проверок |
| Confluence | Ведение тестовой документации, анализ требований и подготовка тестового отчёта |
| Jira | Регистрация, описание и отслеживание дефектов |
| GitHub | Хранение и представление тестовой документации и результатов проекта |

## Этапы тестирования

1. **Анализ требований** — изучение технического задания, определение проверяемых функций и условий валидации.
2. **Подготовка тестовой документации** — разработка чек-листов и тест-кейсов.
3. **Выполнение тестирования** — проведение проверок, фиксация фактических результатов.
4. **Регистрация дефектов** — создание баг-репортов в Jira.
5. **Анализ результатов** — оценка результатов тестирования, расчёт метрик и подготовка итогового отчёта.
