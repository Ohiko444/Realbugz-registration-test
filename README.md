# Тестирование формы регистрации на археологическую экспедицию

## 1. Описание проекта

Проект представляет собой тестирование веб-формы регистрации участников археологической экспедиции.

**Цель тестирования:** проверить соответствие формы требованиям технического задания, корректность валидации пользовательских данных, работу элементов интерфейса и обработку действий пользователя.

## 2. Функциональные требования

| ID | Требование |
|---|---|
| FR-01 | Все обязательные поля формы должны быть отмечены символом `*`. |
| FR-02 | Форма может быть отправлена только при условии, что все обязательные поля заполнены корректными данными. |
| FR-03 | При наведении курсора на текст «Условия использования» должна отображаться подсказка с информацией об использовании отправленных пользователем данных. |
| FR-04 | При успешной отправке формы должно отображаться сообщение об успехе, после чего все поля формы должны автоматически очищаться. |
| FR-05 | Если при отправке формы обнаружены ошибки, рядом с соответствующими полями должны отображаться сообщения об ошибках. |
| FR-06 | При нажатии кнопки «Очистить форму» все введённые данные должны удаляться, а пользователю должно отображаться сообщение об успешной очистке. |
 
## 3. Спецификация требований к полям формы

### 3.1. Обязательные поля

| ID | Поле | Тип элемента | Требования |
|---|---|---|---|
| FL-01 | Имя и фамилия | Текстовое поле | Длина от 2 до 50 символов. Разрешены буквы латинского и русского алфавита, пробелы, дефисы и апострофы. Цифры и остальные специальные символы не допускаются. Поле не может быть пустым. |
| FL-02 | Email | Текстовое поле | Максимальная длина — 100 символов. Необходимо проверить корректность формата email (например, `test@example.com`). Поле не может быть пустым. |
| FL-03 | Контактный номер | Текстовое поле | Максимальная длина — 15 символов. Допускаются только цифры, символы `+`, `-` и пробелы. Поле не может быть пустым. |
| FL-04 | Дата рождения | Поле ввода даты | Формат `DD/MM/YYYY`. Возраст пользователя должен быть строго больше 18 и строго меньше 70 лет на текущую дату. Поле не может быть пустым. |
| FL-05 | Опыт в археологии | Выпадающий список | Значение по умолчанию — «Нет опыта». Поле обязательно для заполнения. |
| FL-06 | Желаемая роль в экспедиции | Группа чекбоксов | Доступные варианты: Исследователь, Фотограф, Оператор дрона, Картограф, Медик, Логист. Допускается выбор нескольких вариантов. Необходимо выбрать хотя бы один вариант. |
| FL-07 | Предпочитаемый регион экспедиции | Группа радиокнопок | Доступные варианты: Южная Америка, Африка, Азия, Европа, Австралия. Можно выбрать только один вариант. Необходимо выбрать один вариант. |
| FL-08 | Загрузить паспорт/ID | Поле загрузки файла | Допустимые форматы: JPG, PNG, PDF. Максимальный размер файла — 5 МБ. Поле не может быть пустым. |
| FL-09 | Я согласен с условиями | Чекбокс | Обязательное согласие. Перед отправкой формы необходимо установить отметку. Если согласие не предоставлено, отправка формы должна быть заблокирована, а пользователю должно отображаться соответствующее сообщение. |

### 3.2. Необязательные поля

| ID | Поле | Тип элемента | Требования |
|---|---|---|---|
| FL-10 | Желаемая зарплата в неделю ($) | Ползунок | Минимальное значение — $0. Максимальное значение — $1700. Шаг изменения — $10. Значение по умолчанию — $700. |
| FL-11 | Предпочитаемый метод связи | Группа радиокнопок | Доступные варианты: Email, Телефон, WhatsApp, SMS. Можно выбрать только один вариант. |
| FL-12 | Дополнительный комментарий | Многострочное текстовое поле | Максимальная длина — 1000 символов. Допускаются любые символы. |

## 4. Ожидаемый результат тестирования

По результатам тестирования необходимо:

- Проверить соответствие формы требованиям технического задания.
- Проверить корректность валидации обязательных и необязательных полей.
- Проверить работу всех элементов пользовательского интерфейса.
- Проверить корректность отправки и очистки формы.
- Выявить и задокументировать обнаруженные дефекты.
- Определить серьёзность (Severity) и приоритет (Priority) каждого обнаруженного дефекта.

**Итоговый результат:** тестовый отчет.
